┌─────────────────────────────────────────────────────────────────────────────┐
│                    COOKIE PERSISTENCE TIMELINE                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   Time │ Action                    │ Cookie           │ Persists          │
│   ─────┼──────────────────────────┼──────────────────┼──────────────────  │
│   0:00 │ First visit               │ [not set]        │ until set         │
│        │ (defaults to light)       │ → light          │ for 1 year        │
│        │                           │                  │                   │
│   0:01 │ User toggles to dark      │ dark             │ for 1 year        │
│        │ API call updates cookie   │ (refreshed)      │ from toggle time  │
│        │                           │                  │                   │
│   2:00 │ Browser closed            │ dark (persisted) │ in browser        │
│        │                           │                  │                   │
│   3:00 │ Browser reopened          │ dark (loaded)    │ still valid       │
│        │ Page load reads cookie    │ no change        │ for ~364 days     │
│        │                           │                  │                   │
│  365d  │ Cookie expires            │ removed          │ defaults to light │
│        │ on next visit             │ → light          │ on next visit     │
│        │                           │                  │                   │
└─────────────────────────────────────────────────────────────────────────────┘
